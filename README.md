# 旗デザイン・紋章学クリエイターゲーム

紋章学のルールに基づいてオリジナルの旗をSVGで作成するインタラクティブツール。

## 概要

SVG 300×200の旗キャンバスに、背景色・模様・シンボルを組み合わせてオリジナルの旗を設計する。作成した旗はPNGとしてダウンロード可能。SVGコードも確認できる。

## 機能

- **背景色**: 7色から選択（赤・青・緑・黒・白・金・紫）
- **前景色**: 6色から選択（模様・シンボルに適用）
- **模様**: 無地・縦縞・横縞・十字・斜め十字・スカンジナビア十字・三色縦割り・三色横割り
- **シンボル**: 五芒星・六芒星・三日月・剣・盾・ライオン・鷲・王冠
- **シンボル2色目**: シンボルの細部色を別途選択可
- **PNG保存**: canvas.toDataURLによるダウンロード
- **SVGコード表示**: 作成したSVGのソースコードをコピー可能

## 技術仕様

- バニラJS + SVG DOM API
- 紋章学の基本構造（フィールド・パターン・チャージ）を実装
- すべてのシンボルはSVGパスで描画（外部画像なし）
- XMLSerializerによるSVG→Canvas変換でPNG出力
